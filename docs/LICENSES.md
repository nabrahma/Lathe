## Downloaded or detected at runtime

These are **not** bundled. Lathe fetches or finds them on your machine, and
each keeps its own licence.

| Component | Licence | How Lathe gets it |
|---|---|---|
| [FFmpeg](https://ffmpeg.org) | GPL-3.0 (the static builds Lathe fetches) | Downloaded on request, checksum-verified |
| [Tesseract](https://github.com/tesseract-ocr/tesseract) | Apache-2.0 | Detected on your system |
| [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast) | Apache-2.0 | Downloaded on request |
| [LibreOffice](https://www.libreoffice.org) | MPL-2.0 | Detected on your system |
| [Ghostscript](https://www.ghostscript.com) | AGPL-3.0 | Detected on your system, optional |

**Why this distinction matters.** The FFmpeg static builds are GPL. Because
Lathe downloads them at runtime rather than bundling them, and communicates
with them only as separate processes over a command line, it is not a
derivative work of them. Bundling a GPL FFmpeg build into the installer would
change that analysis, and must not be done without revisiting D4.

AGPL was chosen partly so this question is uncomfortable in only one direction:
every component's licence is compatible with it, and nobody can re-host Lathe as
a paid service without publishing their changes.

## The test corpus

Every file in `testdata/corpus/` is generated by `scripts/gencorpus` from code
in this repository. Nothing was collected from elsewhere, so the corpus carries
the repository's own licence and can be redistributed without qualification.
